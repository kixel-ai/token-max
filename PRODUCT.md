# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

The product itself is a terminal CLI. Its design surfaces are the
max.kixel.ai landing page, the README, the logo, and the styling of
`token-max doctor`'s terminal output.

## Users

Two audiences, weighted equally:

- People on Claude or ChatGPT plans who run heavy Claude Code or Codex
  sessions and hit their usage limits. To them, dollars stand in for a share
  of the plan's limit.
- People on an API key, to whom the same dollars are close to the bill.

Both arrive deciding whether to run an unfamiliar tool against their own
transcripts, then run `token-max doctor` in a terminal and walk its changes.

## Product Purpose

token-max reads this machine's Claude Code and Codex transcripts and
settings, replays the sessions at public API prices, and tells the person
which settings use more of their limits or bill than they return. Then it
offers to change them, one at a time, writing a settings file only after
showing the change and getting a yes. Success is a user who changes
settings because of evidence they can check, and who runs it again later.

## Positioning

Most advice about configuring coding agents is asserted, not measured.
token-max shows its evidence: every recommendation is labeled Measured
(replayed from the user's own transcripts), Official (the provider's cited
guidance) or Opinion (the maintainer's preference), and never presents one
kind as another. It says plainly when a cost can't be measured instead of
guessing a number. As of the 2026-11-05 survey in `quest/m0/README.md`, no
other tool recommends settings from transcripts for both harnesses.

## Operating Context

- Installed with a one-line `curl | sh` or PowerShell script from
  max.kixel.ai, `cargo install`, `cargo binstall` or Nix. `run.sh` and
  `run.ps1` run `doctor` without installing.
- `doctor` is interactive on a terminal: a walk through the changes, biggest
  saving first, then one confirm. Piped or under `NO_COLOR`, it prints a
  plain report and edits nothing.
- Readers judge it in the README on GitHub, on crates.io, and on
  max.kixel.ai.

## Capabilities and Constraints

- Checks: prompt cache TTL, auto-compact window, idle compaction, tools,
  skills and MCP servers, instruction files, fast mode, effort, auto memory,
  background features, the Bash timeout cap, keepalive pings, subagent
  types, and Fable weekly use. `docs/reference.md` is the full list.
- Privacy: transcripts are only read; no prompt, reply, tool argument or
  tool output text is kept or printed. The only network request is the
  models.dev price list, unless `--ssh` names other machines.
- Dollars are public API prices, not an invoice. No provider publishes plan
  limits in tokens or dollars.
- The site is one hand-written HTML and CSS page in `site/public`, with no
  build step, served as static assets by a Cloudflare Worker at
  max.kixel.ai. `/install.sh`, `/install.ps1`, `/run.sh` and `/run.ps1` must
  keep working.
- The terminal output style was chosen as "polished lines" (bold headline,
  colored verdict dots, dim secondary text, aligned columns), not boxed
  cards or badges with bars. `quest/m0/launch/style.md` holds the details.
- The logo is SVG drawn by hand in code, with no embedded raster images or
  fonts, in mark, mark plus wordmark, light, dark and 16 px favicon forms.
- Undecided: the logo (the maintainer picks from 4-6 concepts in
  `quest/m0/launch/logo.md`).

## Brand Commitments

- Name: `token-max`, lowercase.
- Maker: presented as made by kixelated, with kixelated's avatar.
- Visual register: the developer-tool standard, played straight, at the
  craft level of Bun, Linear, Vercel, Charm and Astral. No metaphor
  costumes, printed-form parodies or retro hardware (the maintainer rejected
  two rounds of them as gimmicky, dated, unexciting and wrong for
  developers).
- Voice: plain and evidence-first. Short sentences, claims labeled by kind,
  unknowns stated as unknown, no hype.
- Verdict colors in the CLI: red for a recommended change, yellow for one
  worth considering, green for a setting already at its recommended value,
  a dim hollow dot for no verdict; savings in green.
- `favicon.svg` (purple stair-steps on slate, made for T3 Code) is a
  placeholder that the picked logo replaces. It binds nothing.

## Evidence on Hand

- Synthetic transcripts in `test/fixtures` for recordings and examples.
  Any sample output says it is synthetic.
- Planned: a dated snapshot of `doctor` on the maintainer's own host,
  showing what those settings save against the defaults, regenerated by
  hand. It publishes real dollars, percents and request counts, and replaces
  private skill names, MCP servers and paths with generic labels. Not yet
  taken.
- Planned: a VHS recording of the walk on synthetic transcripts, checked in
  with its tape.
- kixelated's avatar is not in the repository yet.
- None on hand, so never fabricate: user counts, testimonials, stars,
  press, or savings figures other than the maintainer's snapshot.

## Product Principles

1. Show the evidence. Every claim names its kind and what it rests on.
2. Say unknown when it is unknown, never zero and never a guess.
3. Nothing leaves the machine, and no prompt or reply text is shown.
4. Ask before writing. Show each change, then write it only after a yes.
5. Lead with the user's own money: their measured saving is the pitch.

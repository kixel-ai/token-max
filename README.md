Most advice about configuring coding agents is asserted, not measured.
token-max reads this machine's Claude Code and Codex transcripts, replays them
under other settings at public API prices, and tells you which settings use up
more of your plan's limits than they return. Then it offers to change them, one
at a time, and shows the edit before writing it.

![token-max doctor walking through three changes on synthetic transcripts](https://raw.githubusercontent.com/kixel-ai/token-max/main/assets/demo/walk.gif)

<sub>The recording runs on [synthetic transcripts](https://github.com/kixel-ai/token-max/blob/main/assets/demo/home.py), not a real host.</sub>

Run it once without installing anything, or install it:

```sh
curl -LsSf https://max.kixel.ai/run.sh | sh
curl -LsSf https://max.kixel.ai/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://max.kixel.ai/run.ps1 | iex
irm https://max.kixel.ai/install.ps1 | iex
```

These work from the first release on; until then, see [Install](#install).

## On the maintainer's workstation

On 2026-11-16, `token-max doctor` read 55 days of the maintainer's own use:
**1,084,868 requests, at least $66,151 at API prices**, across two Claude Code
profiles (one on a plan, one on API usage credits), Codex and T3 Code.

- **Its settings already save up to $514/mo, 1% of the spend, against the
  defaults.** The usage credits profile keeps its prompt cache for 1h instead
  of the 5m default for API keys and credits. 13 more settings differ from
  their defaults by amounts it could not measure, and it says so instead of
  guessing.
- **It still found 55 changes**: 28 recommended, because a tool or skill was
  never used, and 27 worth considering, because one cost more than $1 per use.
  They are 37 skills and 18 built-in tools, each saving $31/mo or less, led by
  the `dataviz` skill ($31/mo), the Workflow tool ($30/mo), the ScheduleWakeup
  tool ($25/mo) and the `code-review` skill ($22/mo).
- **It shows where the money went**: in the main Claude profile,
  general-purpose subagents cost at least $34,543 (52%), Bash output with no
  size cap $10,790 (16%), and main sessions at `high` effort at least $7,206
  (11%).

The savings are small against this spend; the point is that each one is
measured on this host instead of promised. The figures are a dated snapshot,
regenerated by hand. Names of the maintainer's private skills, MCP servers and
paths are left out, and no prompt or reply text is published.

## How it measures

Every line names the kind of claim it rests on, so a preference never reads as
a measurement:

- **Measured**: replayed from your own sessions at public API prices, saying
  what the replay held constant and what it could not measure.
- **Official**: the provider's own guidance, cited beside what your sessions
  show.
- **Opinion**: the maintainer's preference, such as fast mode off, beside
  whatever was measured.

No provider publishes a plan's limits in tokens or dollars, so API prices are
the closest public measure of what a request uses of them; on an API key they
are close to your bill. A cost it cannot measure is shown as unknown, never as
zero.

## What stays on your machine

Transcripts are only read, and no prompt, reply, tool argument or tool output
text is kept or printed. The only network request downloads public prices from
`https://models.dev/api.json`, unless you name other machines with `--ssh`.
Nothing is written until you accept a change and then confirm the list of
edits.

## Install

From the first release on, each GitHub release has prebuilt binaries for
Linux (x86_64 and arm64, statically linked), macOS (Apple silicon and Intel)
and Windows (x86_64). `install.sh` and `install.ps1` above are the release's
installers, which put `token-max` in `~/.local/bin` by default. `run.sh` and
`run.ps1` download the binary to a cache instead, check it against the
release's checksum, and run `token-max doctor`; the
[reference](https://github.com/kixel-ai/token-max/blob/main/docs/reference.md#running-it)
says how to pass it options.

`cargo binstall token-max` downloads the same binary, and
`cargo install --locked token-max` builds it. On Linux and Apple silicon,
Nix builds it from source:

```sh
nix run github:kixel-ai/token-max -- doctor
```

Until that release, install from GitHub with a Rust toolchain:

```sh
cargo install --locked --git https://github.com/kixel-ai/token-max
```

## Run

```sh
token-max doctor                     # every Claude Code and Codex profile on this host
token-max doctor --since 2026-11-01  # only sessions from that date on
token-max doctor --details           # the evidence behind every line
token-max doctor --help
```

## What it checks

| Setting or feature | What the report says |
| --- | --- |
| Prompt cache TTL (5m or 1h) | Which lifetime would have cost less on your sessions |
| Auto-compact window | Whether a different window would have cost less, summaries included |
| Idle compaction | Whether compacting sessions you walked away from paid for itself |
| Tools, skills and MCP servers | What each cost to send with every request, and how often it was used |
| Instruction files | What each CLAUDE.md or AGENTS.md cost, beside the provider's size guidance |
| Fast mode | What the premium cost; recommended off |
| Main-session effort | What each model and effort cost, beside the provider's guidance; `max` recommended down to `xhigh`, `low` worth considering raising |
| Auto memory | What loading, reading and writing it cost, and how often it was used; worth considering off |
| Prompt suggestions, recaps, check-ins | What each background feature cost, where it can be estimated |
| Bash timeout cap | Whether long foreground waits let the cache expire |
| Keepalive pings | Whether pinging idle sessions would beat the cache misses |
| Subagent types | What each cost, which model and effort it ran on, and the same tokens on the cheapest current model, beside Anthropic's model guide |
| Fable weekly use | Each week's Fable spend beside Anthropic's rule that, on Max and Ultra plans, Fable can use up to half the weekly limit |

See the [reference](https://github.com/kixel-ai/token-max/blob/main/docs/reference.md#reading-the-report)
for how to read each line, and its sections for each check.

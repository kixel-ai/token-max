# Results on the maintainer's machines

The README and [max.kixel.ai](https://max.kixel.ai) lead with figures from
`token-max doctor --details --since 2026-10-18T15:18:57Z`, run 2026-11-17 on
each of the maintainer's four machines: a macOS laptop and three Linux hosts.
They are a dated snapshot, regenerated by hand; change all three together.
Names of the maintainer's private skills, MCP servers and paths are left out,
and no prompt or reply text is published.

## Totals

doctor reports each machine on its own and never adds machines together, so
these totals are its four header lines added by hand:

| Machine | Requests | Sessions | API cost | Changes save together |
| --- | --- | --- | --- | --- |
| Laptop (macOS) | 29,678 | 201 | ~$2,275 ± $13 | ~$104/mo |
| Workstation | 759,060 | 7,192 | ~$44,141 ± $70 | ~$423/mo ± $0.12 |
| Server | 203,510 | 1,983 | ~$12,928 ± $131 | ~$18/mo, plus 1 change not measured |
| Second workstation | 174,388 | 2,421 | ~$9,878 ± $4.76 | ~$176/mo |
| **All four** | **1,166,636** | **11,797** | **~$69,222 ± $149** | **~$721/mo ± $0.12** |

- **API cost** is every recorded Claude Code, Codex and T3 Code request at
  public API prices, extrapolated over the requests that could not be priced
  (`~`, with a 95% margin). The total's margin combines the machines' in
  quadrature, as doctor combines profiles. The machines are summed as they
  are: a history copied from one to another would count on both.
- **Sessions** count each Claude Code session and Codex thread once, with the
  subagents and review threads it spawned. The machines also ran 8,166
  subagents.
- **Changes save together** is the line under each report's headline: what
  every change doctor offers saves at the window's rate, recommended and worth
  considering alike. Each saving holds the other settings constant, so
  overlapping changes may save less. Almost all of it is skills and built-in
  tools that were never used or cost more than $1 per use, led by the
  `dataviz` skill, the Workflow tool, the ScheduleWakeup tool and the
  `code-review` skill.

doctor asked how each Claude profile pays, and each answer came from the
profile's account (`oauthAccount.billingType` in its `.claude.json`): every
machine's `~/.claude` is on a plan, and the usage credits profiles, plus an
archived profile with no account, were answered as API.

## Prompt cache TTL

Replays of the same sessions at 5m and 1h, summed over the four machines. Each
is a Measured line in its profile's `settings.json`; the cost is the cache's
over the 30 days.

| Setting | Profiles | 5m | 1h | 1h against 5m |
| --- | --- | --- | --- | --- |
| `subagentPromptCacheTtl` | plan, unset (5m) | ~$24,312 | ~$20,170 | ~17% less, ~$4,143 ± $30 |
| `promptCacheTtl` (main agent) | usage credits, set to 1h | ~$1,393 | ~$874 | ~37% less, ~$519 ± $2.08 |

On the plan profiles doctor shows both lines as "not enough evidence": the
replay favors 1h, but it could not confirm the current setting applies to the
sessions, so neither is in the totals above.
[How context is priced](reference.md#how-context-is-priced) describes the
rule. The usage credits profiles already set both to 1h; on their few
subagent requests 5m was cheaper, by ~$3.63 over the window, and doctor
recommends going back, a change the totals include.

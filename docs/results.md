# Results on the maintainer's workstation

The README and [max.kixel.ai](https://max.kixel.ai) lead with two figures from
`token-max doctor --details` on the maintainer's workstation, run 2026-11-17
over 56 days: 1,084,999 requests, at least $66,190 at API prices, across two
Claude Code profiles (one on a plan, one on API usage credits), Codex and
T3 Code. They are a dated snapshot, regenerated by hand; change all three
together. Names of the maintainer's private skills, MCP servers and paths are
left out, and no prompt or reply text is published.

## Prompt cache TTL

Both are Measured lines for the plan profile's `~/.claude/settings.json`,
replaying the same sessions at 5m and 1h:

| Setting | Default | 1h against 5m | Requests priced |
| --- | --- | --- | --- |
| `subagentPromptCacheTtl` | 5m for everyone | ~14.8% less, ~$6,105 over 56 days | 95.1% (28,082 not) |
| `promptCacheTtl` (main agent) | 1h within a plan's included usage, 5m on an API key or usage credits | ~36% less, ~$7,383 over 56 days | 97.9% (4,280 not) |

`~` marks a figure with requests that could not be priced, such as API
attempts with no recorded usage. They are left out of both sides. `doctor`
itself recommends neither change on this host: it reports "not enough
evidence" while those requests could flip the result, as
[How context is priced](reference.md#how-context-is-priced) describes.

## Everything else it found

An earlier `token-max doctor` run the same day read 56 days of the maintainer's own use:
**1,085,092 requests, at least $66,166 at API prices**, across two Claude Code
profiles (one on a plan, one on API usage credits), Codex and T3 Code.

- **A default user would save about $230/mo or more, plus up to $509/mo from the
  cache TTL.** `token-max doctor --defaults` replays this same history as if no
  settings file existed. It then recommends 29 changes and suggests 31 more:
  38 skills and 18 built-in tools to turn off or make typed-only, a 1h prompt
  cache on the usage credits profile (up to $509/mo, 1% of the spend), and auto
  memory and Codex's effort, whose savings it could not measure and says so.
- **The maintainer's settings already save up to $509/mo against the
  defaults**, from that same 1h cache. 13 more settings differ from their
  defaults by amounts it could not measure.
- **It still finds 55 changes**: 28 recommended, because a tool or skill was
  never used, and 27 worth considering, because one cost more than $1 per use:
  37 skills and 18 built-in tools, led by the `dataviz` skill ($31/mo), the
  Workflow tool ($30/mo), the ScheduleWakeup tool ($25/mo) and the
  `code-review` skill ($22/mo). It also shows where the money went:
  general-purpose subagents cost at least $34,543 (52%), and Bash output with
  no size cap $10,794 (16%).

The savings are small against this spend; the point is that each one is
measured on this host instead of promised.

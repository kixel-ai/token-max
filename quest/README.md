# token-max

## Goal

A heavy Claude Code or Codex user runs `token-max` and learns which agent
settings would have cost less on their own sessions, with the evidence and
the dollars at public API prices, without the tool ever editing a setting or
printing a prompt.

- [m0: first release](/quest/m0/README.md) - token-max 0.1.0 on crates.io with the cache, compaction window, idle compaction, Bash cap, skills catalog, and keepalive checks

# Launch token-max

## Goal

Before 0.0.1 ships, someone landing on [max.kixel.ai](https://max.kixel.ai)
or the README sees a logo, a clear pitch, and the maintainer's real measured
results, and running `token-max doctor` gives a colorful, well-formatted
report that says in plain words what each setting does and how much the
current settings already save against the defaults. Launch posts and
promotion, a hosted web app that runs doctor, and telemetry are outside it.

## Plan

Decided 2026-11-15 (maintainer, /quest-plan after a local `doctor` run on
the maintainer's host): ✅ better marketing and a prettier CLI before the
0.0.1 release ("before we release we need better marketing"), so
[the release](/quest/m0/release.md) waits for this epic.

✅ The real results are a dated snapshot of a run on the maintainer's host,
regenerated by hand, showing what the maintainer's settings save against the
defaults ("pretend I'm using defaults"). Publish real dollars, percents and
request counts, and the names of built-in and public settings, tools and
skills; replace private skill names, MCP servers and paths, such as the
maintainer's own `quest-*` and `verify-*` skills and worktree paths, with
generic labels (rejected: everything verbatim, which publishes private names;
aggregates only, which convinces less). Never publish prompt or reply text.
The README's "On the maintainer's workstation" section holds the snapshot,
taken 2026-11-17 on `desktop`, and the [site](/quest/m0/launch/site.md)
reuses it.
